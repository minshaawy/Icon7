# مكتبة الأيقونات المتحركة

صفحة واحدة (`index.html`) فيها ٦٥٧ أيقونة متحركة بـ ٦ ستايلات، منها معلم لكل دولة عربية، وتصدير لفيجما وLottie وGIF. الموقع إنجليزي افتراضيًا وفيه زرار يحوّله لعربي.

## ترفعها على النت إزاي (مجانًا)
أي استضافة ملفات ثابتة تنفع، لأن الموقع ملف HTML واحد:

- **Netlify Drop:** افتح app.netlify.com/drop واسحب الفولدر كله جوه الصفحة، وهيديك لينك على طول.
- **GitHub Pages:** ارفع الفولدر على ريبو، وفعّل Pages من إعدادات الريبو.
- **Vercel** أو **Cloudflare Pages:** نفس الفكرة، ارفع الفولدر واختار إن مفيش build.

خلي اللينك يبدأ بـ https علشان زراير النسخ تشتغل. التحميل في النسخة دي شغال تحميل عادي من المتصفح.

## تكمّل الشغل في Claude Code
1. افتح الفولدر ده في Claude Code.
2. ملف `CLAUDE.md` فيه كل اللي اتعمل والقرارات والمشاكل اللي اتحلت، وClaude Code بيقراه لوحده.
3. حط الريفرانسات في `references/`، والألوان والخطوط في `brand/`.

## الرخص
- الأيقونات الأساسية من Lucide برخصة ISC، ودي بتسمح بالاستخدام التجاري.
- الأيقونات المحلية وطقم التأمين مرسومين مخصوص للمكتبة دي.
