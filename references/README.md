# Animation references

Drop motion references here, then ask Claude Code to study them.

- Best: Lottie `.json` files (exact timing and easing can be read from them).
- Also fine: short `.mp4` / `.gif` clips, or screenshots of motion curves.
- Add one line per file in `notes.md`: what you like about it (bounce, speed, feel) and which icons it should influence.
- Paid libraries (e.g. Lordicon) are style references only: don't copy their drawings or exact animations.
